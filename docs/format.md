# San13PK 语音库格式逆向笔记

对一组繁体中文 PK 数据布局的观察记录。具体偏移见 `data/layout.json`；不表示其他版本已兼容。KOVS 容器与索引 XOR 为已有公开知识，见 [vgmstream 源码](https://github.com/vgmstream/vgmstream/blob/master/src/meta/ogg_vorbis.c) 的 `kovs_ogg_decryption_callback`。本项目的槽区与分配流程不改变这些来源的归属。

## 1. 帧表（slot directory）

- 帧表基址 `BASE = 0x894B8600`，共 **4015 项**，每项 8 字节 `(span, off)`，均为小端 `u32`。
- 帧表起始处 `u32` 读数应恰好为 4015（首项 span 字段兼任计数），不符说明现役包被改动，必须停止施工。
- 表项 N 位于 `BASE + N * 8`；`off` 为相对 BASE 的偏移，槽 N 语音数据绝对地址 = `BASE + off`。
- 槽数据按 off 排序后，槽与下一槽的差即该槽的**物理间隙**（gap）——替换载荷不得超过它。

## 2. KOVS 槽结构

```
偏移   长度   含义
0x00   4     魔数 "KOVS"
0x04   4     u32 流长 decl（Vorbis 流字节数）
0x10   1     flag，正常语音 = 1
0x11   1     loop，正常语音 = 0
0x20   decl  Vorbis 流（前 0x100 字节经索引 XOR）
```

- **游戏按 `u32@4` 的流长读取，无视帧表 span**——因此替换帧只需 ≤ 物理间隙，帧表可原样不动。
- 封装时补零至 `max(原decl+32, 载荷长+1)` 且不超过 gap；末个物理槽的 gap 由文件尾计算。逻辑槽号只索引原始帧表，物理排序仅用于查找下一偏移。

## 3. 索引 XOR（关键，漏了 = 静音）

Vorbis 流的**前 0x100 字节按字节索引异或**：`stream[i] ^= i`。

- 明文流以 `OggS` 开头（0x4F 0x67 0x67 0x53），XOR 0,1,2,3 后即包内所见 `OfeP`。
- 注入时必须先封装后写入；直接写裸 `OggS` 流，游戏读取正常、字段/哈希全对，但**完全无声**（实测踩坑）。

## 4. 编码参数（实测可用的安全组合）

- 24kHz 单声道 libvorbis ABR 16kbps + `loudnorm=I=-16` + 40ms 淡入 / 70ms 淡出；
- 实测码率约 3.4KB/s，用作容量预算的保守值（`BYTES_PER_SEC = 3400`）；
- ffmpeg 一律经 stdout 管道取流写盘（`-f ogg -`），直接写文件可能被杀软拦截。

## 5. 槽区布局与段界短应答簇

- 全表按内容分区：战斗区约 840–2060，对话区约 2060–4015（脚本内 `REGION_BATTLE` / `REGION_DIALOG` 为扫描起点，非硬边界）。
- 名将专属库在对话区呈**连续段**，段结构为：

```
[ 前一位武将主台词 …… ] [ 本武将短应答簇 1~4 槽 ] [ 本武将主台词 …… ] [ 下一位武将…… ]
```

- 靠"自称锚字"静态定位只能圈到**主台词**，短应答簇（我知道了/交给我吧/明白/放手去做吧…）旧版可能停在短应答之前；新版不把“明白”等普通短应答作为系统边界，但这不能自动证明其归属，必须人工确认。
- 判归属：查前一位武将在自己段内是否另有同套应答句——有，则簇归本武将，应纳入注入计划。
- 系统行（传令、战场报告：击败敌将/大本营/援军已经…）不属于任何武将，勿纳入。

## 6. 共享剧本武将表（门禁 1 数据源）

- 共享剧本数据区含 **855 条武将记录**，每条步长 `0x1B0`；
- 武将记录内"语音库号"字节位于记录基准（0x60C1）前 8 字节处，取值即 Voice 库编号；
- 独占性判定：某 Voice 号在 855 条中被引用次数 = 1，才允许作为注入目标（防止改动共享库波及大众脸）。
- 本工具从"共享剧本导出副本"（`SAN13PK_EXPORT`）做上述字节级复验；导出副本由使用者从自己持有的游戏数据自行产出。

## 7. 定位策略（ASR）

- 全表 4015 槽先以本地 whisper 模型转写并缓存于 `data/asr-cache/slotN-<内容指纹>-small.txt`（首次 2~4 小时，可断点续跑）；
- 定位用 **small 模型**文本（base 会听错人名：孔明→孫明、袁绍→原本初）；
- 锚字 = 武将自称特征（表字/称号/口头禅），由 `data/officers.json` 的 `markers` 提供；
- 扫描按 stride 3 探针，命中后向两侧扩展至他库/系统行/空文本为止，结果只作为未验证候选，每区至少两处锚点；人工确认首尾、短应答簇和两侧归属后才可 confirm-bank。
